A ZCode plugin that turns reference imagery into a working Tamil TrueType font — fully agentically. Any image → TTF: posters, signboards, handwriting scans, or drawn template sheets.

In these two runs the poster titles failed the legibility gate — the lettering is fused with artwork, and every extracted crop scored far below the bar — so both fonts ship fully backfilled: 296/296 cells, every glyph shape-gated against the base font. How it works

1 · template

Generates 14 A4/300dpi sheets covering 296 cells — 12 uyir + ஃ + 18 consonants + 13 signs + 18 pulli forms + 198 uyirmei + numerals, grantha, digits, punctuation — with in-cell baseline/headline guides and corner fiducials.

2 · ingest (3 modes)

Digital sheets (exact-geometry crop), paper photos (numpy fiducial detection + perspective warp — no opencv), or agent-vision extraction from arbitrary images: the agent crops, classifies by reading, and picks faithful/clean cleanup presets.

3 · trace → build

potrace → cu2qu → 2048-upm TrueType via fonttools, with the 270 ligature rules generated from one mapping table. Precomposed uyirmei sidestep matra reordering entirely. Lookups registered under ccmp + liga (HarfBuzz's Tamil shaper ignores plain liga — found empirically).

4 · verify (agent QA)

Programmatic gates: non-empty rasters, em-bounds, shaping identities (கி → one glyph; composed == decomposed கௌ), notdefs vs coverage, and per-glyph shape similarity against the base font (min IoU 0.5 — a green verdict is unreachable without it). Visual gates: HarfBuzz-rendered charts, and a real-word chart the agent must transcribe by eye before anything ships.

Bootstrap-proven, not just plausible

Before any human art, the test suite rasterizes Noto Sans Tamil into the pipeline's own formats and gates the full roundtrip: B1 digital sheets (296/296 traced, 270/270 rules, per-glyph IoU), B2 synthesized phone photos (perspective ≤ 70 px jitter, noise, uneven light → fiducial deskew), B3 poster-like extraction with occlusion flagging and partial-font degradation. 56 tests green.

Use it

$ git clone https://github.com/srikanthlogic/tamil-font-maker && cd tamil-font-maker
$ python3 -m venv --without-pip .venv
$ pip3 --python .venv/bin/python install fonttools uharfbuzz potracer cu2qu Pillow brotli pytest
$ .venv/bin/python -m pipeline.cli init projects/myfont --family "My Font"
$ .venv/bin/python -m pipeline.cli template projects/myfont   # draw the sheets, or drop images in samples/
$ .venv/bin/python -m pipeline.cli ingest-digital projects/myfont sheets/S1.png
$ .venv/bin/python -m pipeline.cli ingest-extract projects/myfont g_u0B95=crops/ka.png --preset faithful
$ .venv/bin/python -m pipeline.cli trace projects/myfont && \
  .venv/bin/python -m pipeline.cli build projects/myfont && \
  .venv/bin/python -m pipeline.cli verify projects/myfont

The full agent protocol lives in skills/tamil-font-maker/SKILL.md. Partial fonts degrade legibly (spacing matras), and template --only … emits completion sheets for exactly the missing cells — or backfill completes them from any base font, as these two poster runs ended up doing after their extracted titles were rejected by the legibility gate.
